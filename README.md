# Happy Birthday, Mirit Bhai! 🎂

A responsive animated birthday microsite built with plain HTML, CSS and JavaScript.

## Features
- Cinematic night sky with twinkling stars, moon glow and ambient gradients
- Responsive design for phones, tablets and desktops
- CSS birthday cake with interactive candles and a wish reveal
- Canvas confetti and multi-burst fireworks
- Original synthesized celebration melody using the Web Audio API (no audio download)
- Keyboard-accessible candles and reduced-motion support

## Run locally
No build tools or dependencies are needed. Download or clone this repository and open `index.html` in a modern browser.

## Publish with GitHub Pages
Open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Customize
Change the greeting and message in `index.html`, visual styling in `style.css`, and interactions in `script.js`.
